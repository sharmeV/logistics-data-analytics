# Logistics Data Analytics

## Project Overview
This project focuses on data collection, cleaning, preprocessing, and exploratory analysis for logistics and last-mile delivery operations.

## Project Objectives
- Inspect dataset structure and data types.
- Identify missing values and duplicate records.
- Convert timestamps and numerical fields where applicable.
- Validate delivery distances and delivery durations.
- Identify potential outliers for further investigation.
- Export a cleaned dataset and a data quality report.

## Tools and Technologies
- Python
- Pandas
- GitHub

## Project Files
- `week2_data_cleaning.py` — Python script for data cleaning.
- `requirements.txt` — Python dependency list.
- `deliveries.csv` — input dataset required by the script.
- `deliveries_cleaned.csv` — cleaned output generated by the script.
- `data_quality_report.txt` — data quality report generated by the script.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install dependencies:

   `pip install -r requirements.txt`

5. Place your permitted dataset in the folder and name it `deliveries.csv`.
6. Run the script:

   `python week2_data_cleaning.py`

## Data and Validation Notes
The script expects certain column names, including `dispatch_time`, `actual_delivery_time`, `distance_km`, and `parcel_weight_kg`. These names must be checked against the actual dataset before running the analysis.

Potential outliers are flagged for review rather than automatically deleted. Outputs should be verified after execution.
